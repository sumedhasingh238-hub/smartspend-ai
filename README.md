
# SmartSpend AI

SmartSpend AI is an intelligent student budgeting companion that stops overspending at the exact moment of purchase.

## Tech Stack & Tools Used
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
* **AI Tool:** Gemini (leveraged for AI-assisted prototyping, code structuring, and building the real-time "Want vs. Need vs. Goal" behavioral reflection engine)
* **Sponsor Integration:** PayPal JavaScript SDK & Sandbox Webhooks (used to simulate secure online checkout flows and automatically update live student balances)

## Setup & Running Instructions
1. Clone or download this repository to your local computer.
2. Open the project folder.
3. Double-click the `index.html` file to open it directly in any modern web browser. No complex server setup or installation is required!
4.Scroll down and click commit changes
